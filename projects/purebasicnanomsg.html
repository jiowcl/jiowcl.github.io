Two Packages, Side by Side

Same repo — pick the stack that matches your needs

PureBasicNanoMsg

Classic libnanomsg binding. Ideal for existing nanomsg code and wire-compatible peers.

  • NanomsgSocket · NanomsgRuntime
  • nn_socket(AF_SP, protocol) style
  • Bind / Connect · nn_errno
  • Bundled: Library/x64/nanomsg.dll
Legacy · Sustaining
Recommended

PureBasicNNG

Modern NNG (nanomsg-next-gen). Prefer this for new projects.

  • Protocol helpers: PubOpen, SubOpen, …
  • Listen / Dial · success = #NNG_OK
  • Errors returned directly (no nn_errno)
  • Bundled: Library/x64/nng.dll

nanomsg Binding Features

Module API

NanomsgSocket, NanomsgRuntime — structured PureBasic modules with clear error paths.

Typed Sockopts

SetsockoptString for topics, SetsockoptInt for timeouts — matching the C API cleanly.

Poll & Zero-Copy

NnPoll / NnPollFd, plus Allocmsg / Freemsg with #NN_MSG.

Scatter / Gather

NnSendmsg / NnRecvmsg with NnIovec / NnMsghdr (see SendmsgIovec example).

Cached Exports

NnDllOpen resolves all nn_* exports once into gNnFuncs — later calls reuse the cache.

x64 Runtime

Bundled nanomsg.dll under Library/x64. Examples require x64 PureBasic.

PUB / SUB Example (nanomsg)

Prefix the published message so it matches the subscriber filter

Publisher (excerpt) PureBasic · x64 
IncludeFile "../../Core/Enums.pbi"
IncludeFile "../../Core/NanomsgWrapper.pbi"
UseModule NanomsgWrapper

Define Socket.i = NanomsgSocket::Socket(#AF_SP, #NN_PUB)
Define Rc.i     = NanomsgSocket::Bind(Socket, "tcp://*:1689")

While 1
  Define topic.s = "quotes"
  ; Prefix must match NN_SUB_SUBSCRIBE on the subscriber
  Define msg.s = topic + "#Bid:" + Random(9000, 1000)
  Rc = NanomsgSocket::SendString(Socket, msg, Len(msg), 0)
  Delay(500)
Wend
Subscriber (excerpt) nn_recv has no null terminator 
Define Socket.i = NanomsgSocket::Socket(#AF_SP, #NN_SUB)
NanomsgSocket::Connect(Socket, "tcp://localhost:1689")
NanomsgSocket::SetsockoptString(Socket, #NN_SUB, #NN_SUB_SUBSCRIBE, "quotes")

Define *buf = AllocateMemory(256)
Define n.i  = NanomsgSocket::Recv(Socket, *buf, MemorySize(*buf), 0)
If n >= 0
  PrintN(PeekS(*buf, n, #PB_Ascii))  ; use returned length
EndIf
FreeMemory(*buf)
