Two Packages, Side by Side

Same repo — pick the stack that matches your needs

FreeBasicNanoMsg

Classic libnanomsg binding. Ideal for existing nanomsg code and wire-compatible peers.

  • LibNanomsgSocket · LibNanomsgRuntime
  • Socket handles are Long (C int)
  • Bind / Connect · nn_errno / Strerror
  • Runtime: Library/x64/nanomsg.dll
Legacy · Sustaining
Recommended

FreeBasicNNG

Modern NNG (nanomsg-next-gen). Prefer this for new projects.

  • NNG protocol constructors & updated API
  • Intentionally incompatible with nanomsg binding
  • Active development path
  • Sibling folder in the same repository

nanomsg Binding Features

Type Wrappers

LibNanomsgSocket, LibNanomsgRuntime, LibNanomsgMessage — OOP-style façade over nn_* APIs.

Typed Sockopts

SetsockoptString for topics, SetsockoptInt / GetsockoptInt for timeouts and deadlines.

Zero-Copy

NnAllocmsg / Reallocmsg / Freemsg with size sentinel NN_MSG on send/recv.

Poll

NnPoll / NnPollFd with NN_POLLIN / NN_POLLOUT; timeout in ms (-1 = forever).

Statistics

NnGetStatistic / GetStatistic with NN_STAT_* constants.

Clean Shutdown

NnTerm / LibNanomsgRuntime.Term for multi-thread shutdown.

PUB / SUB Example (nanomsg)

Prefix the published message so it matches the subscriber filter

Publisher (excerpt) fbc PubServer.bas -target win64 
#Include "../../Core/Enums.bi"
#Include "../../Core/NanomsgWrapper.bi"

Dim NnSocketRec As LibNanomsgSocket
Dim NnRuntime   As LibNanomsgRuntime

If LibNanomsgWrapper.DllOpen(lpszLibNnDll) Then
    Dim Socket As Long = NnSocketRec.Socket(AF_SP, NN_PUB)
    Dim Rc As Long = NnSocketRec.Bind(Socket, "tcp://*:1689")

    While 1
        Dim topic As String = "quotes"
        ' Prefix must match NN_SUB_SUBSCRIBE on the subscriber
        Dim msg As String = topic & "#Bid: …,Ask:…"
        Rc = NnSocketRec.Send(Socket, StrPtr(msg), Len(msg), 0)
        Sleep(500)
    Wend
End If
Subscriber (excerpt) nn_recv has no null terminator 
Dim Socket As Long = NnSocketRec.Socket(AF_SP, NN_SUB)
NnSocketRec.Connect(Socket, "tcp://localhost:1689")
NnSocketRec.SetsockoptString(Socket, NN_SUB, NN_SUB_SUBSCRIBE, StrPtr("quotes"))

Dim buf As Any Ptr = CAllocate(256)
Dim n As Long = NnSocketRec.Recv(Socket, buf, 256, 0)
If n >= 0 Then Print(BytesToString(buf, n))  ' copy by returned length
Deallocate(buf)
