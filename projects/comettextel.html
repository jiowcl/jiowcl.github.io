CometTextel

Modern C++ Library for GSM SMS over Serial

C++23 CMake GSM 03.40 PDU Serial / AT C ABI · .NET · Python MIT License

Concise and lightweight. Send and receive short messages through a GSM modem with a clean serial abstraction, full PDU encode/decode, and AT-command helpers — ready as shared or static library.

Key Features

Cross-Platform Serial

Unified SerialPort API with Win32 and POSIX backends — Windows, Linux, macOS.

GSM PDU Codec

7-bit, 8-bit, and UCS-2 encode/decode. Concatenated SMS, UDH, status reports — no MFC or legacy globals.

Modem Helpers

Initialize, send (AT+CMGS), list (AT+CMGL), delete (AT+CMGD) in PDU mode.

Modern C++23

RAII handles, std::error_code, std::span, and clear public headers under include/comettextel/.

Shared & Static

Build as DLL/shared library and/or static archive from one CMake tree. find_package ready.

Multi-Language

Stable C ABI with bindings for C#, Python, PureBasic, FreeBASIC — plus native C/C++.

API Example

Open a modem, send a UCS-2 SMS in a few lines

main.cpp C++23 
#include "comettextel/comettextel.hpp"
#include <iostream>

int main()
{
    comettextel::GsmModem modem;
    comettextel::SerialConfig config;
    config.baud_rate = 115200;

    if (const auto ec = modem.open_and_init("COM3", config); ec) {
        std::cerr << "open/init failed: " << ec.message() << '\n';
        return 1;
    }

    comettextel::Message message;
    message.service_center = "886932000000";
    message.peer_address   = "886912345678";
    message.coding         = comettextel::DataCoding::Ucs2;
    message.user_data      = "Hello from CometTextel";

    if (const auto ec = modem.send_message(message); ec) {
        std::cerr << "send failed: " << ec.message() << '\n';
        return 2;
    }
    return 0;
}
