Vyrn

A Modern Lua-inspired Programming Language

PureBasic Embedded Scripting Optional Typing Bytecode VM MIT License

Concise, lightweight, and designed for small-scale applications and embedded scripting. Built entirely in PureBasic — bringing the familiar elegance of Lua while evolving its own unique language characteristics.

View on GitHub See Example

Key Features

Ultra Lightweight

Minimal footprint with zero extra dynamic libraries needed. Ideal for embedding and small tooling.

Lua-Inspired Syntax

Familiar, clean, and quick to learn for Lua developers — with modern keywords and optional typing.

Built for Embedding

Seamlessly embeddable into host applications written in PureBasic or C via native ABI / DLL.

Optional Typing

Parameter, return, binding and struct annotations with runtime checks; use --strict for compile-time.

Developer Tooling

vyrn build, bundle, serve, REPL, --dump, --strict, --bench and more.

Official Vyrn IDE

Standalone, ultra-lightweight IDE with custom syntax highlighting, multi-file support, and integrated run/debug.

Language Snapshot

Modern keywords with full Lua compatibility

Modern Keywords

def let elif const continue match struct / enum

Legacy function / local / elseif still accepted.

Core Capabilities

  • Optional types & multi-return
  • String interpolation "Hello, {name}!"
  • Closures, upvalues & varargs
  • Coroutines + yield
  • Protected calls (pcall / xpcall)

Quick Example

Vyrn supports both its own syntax and classic Lua style

greet.vyrn Optional Typing 
-- Vyrn (Optional Typing)
def greet(name: string) -> string
    return "Hello, " .. name .. "!"
end

def calculate_bonus(score: number) -> number
    return score * 1.1
end

print(greet("Vyrn"))
print(calculate_bonus(100))

-- Output:
-- Hello, Vyrn!
-- 110

Project History

2016

Initially written as LuaLiteVM in PowerBasic 10.04

2018

Rewritten in FreeBasic 1.05 using FBEdit

2024

Rewritten in the latest PureBasic and renamed to Vyrn

2025

Optional typing, structs/enums, coroutines, strict mode, build/bundle/serve, native C ABI

2026

Official standalone Vyrn IDE released (syntax highlighting, multi-file, run/debug)
