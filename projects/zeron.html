Fast, Lightweight Windows Remote Automation

Driven by NetMQ (ZeroMQ), Zeron empowers SMB IT teams and developers to control systems, deploy software, and build task pipelines via clean JSON-RPC APIs — entirely on your own network.

Why Zeron?

Ultra-Lightweight

Built on NetMQ (ZeroMQ) for high-performance, low-latency messaging with minimal footprint.

Private & Secure

Designed for internal networks and SMB environments — no cloud required, full data ownership.

Developer-Friendly

Standard JSON-RPC APIs for full control over deployments, scheduling, and task pipelines.

Always-On Agent

Reliable background management via Zeron.Demand Windows Service with health checks.

Architecture

Modular components for agents, server, and tooling

Zeron

Shared library — servers, attributes, utilities, and core messaging primitives.

Zeron.Demand

Windows Service agent — always-on, JSON-RPC endpoint, scheduler, package management.

Zeron.Server

Central management server — HTTP API, NetMQ command PUB, multi-agent orchestration.

Zeron.Client

Interactive test console for rapid API exploration and agent debugging.

Dashboard

Blazor Server UI with JWT/Cookie auth, role-based access, live agent overview.

Plugins

Extensible gate plugins (e.g. SampleAgentGatePlugin) for custom agent capabilities.

Task Pipeline Example

JSON-defined multi-step workflows with cron scheduling

Resource/scheduler-tasks.json NCrontab 
{
  "tasks": [
    {
      "name": "daily-serverinfo",
      "cron": "0 8 * * *",
      "enabled": true,
      "steps": [
        {
          "type": "api",
          "apiName": "ServerInfo",
          "command": ""
        }
      ]
    }
  ]
}

Get Started

Build, run, and deploy on Windows

Build

dotnet build Zeron.sln -c Release
dotnet test Zeron.sln -c Release

Run Agent

dotnet run --project Zeron.Demand

Run Server

dotnet run --project Zeron.Server
# Dashboard → http://localhost:5000
